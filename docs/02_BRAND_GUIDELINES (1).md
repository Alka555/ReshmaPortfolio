# Purpose

Define the visual and verbal identity for the portfolio so every page,
component, and interaction feels consistent.

# Brand Essence

**Content Creator • Writer • Freelancer**

The brand communicates thoughtful storytelling through film and words.

## Brand Attributes

-   Premium
-   Editorial
-   Cinematic
-   Modern
-   Minimal
-   Authentic
-   Confident
-   Human

Avoid: - Loud - Over-animated - Corporate - Generic - Template-like

------------------------------------------------------------------------

# Tone of Voice

## Primary

-   Clear
-   Warm
-   Professional
-   Conversational
-   Thoughtful

## Writing Rules

-   Short paragraphs
-   Active voice
-   Minimal marketing language
-   Show work before self-promotion
-   Let visuals lead

-   Inter

------------------------------------------------------------------------

# Spacing Principles

-   Generous whitespace
-   8px spacing system
-   Clear visual rhythm
-   Never overcrowd sections

------------------------------------------------------------------------

# Imagery

Preferred: - Behind-the-scenes photography - Cinematic stills - Natural
lighting - Authentic moments

Avoid: - Generic stock images - Heavy filters - Distracting collages

------------------------------------------------------------------------

# Iconography

-   Lucide Icons
-   Thin stroke
-   Minimal usage
-   Icons support content rather than dominate it

------------------------------------------------------------------------

# Motion Principles

Animation should feel:

-   Calm
-   Smooth
-   Purposeful

Recommended: - Fade - Blur reveal - Gentle scale - Image zoom - Page
transitions

Avoid: - Bounce - Flash - Excessive parallax

------------------------------------------------------------------------

# Components

## Buttons

Primary: - Navy background - Gold hover accent - Rounded corners

Secondary: - Transparent - Thin border

## Cards

-   Rounded (16--20px)
-   Soft shadow
-   Large media
-   Clean metadata

------------------------------------------------------------------------

# Navigation

-   Sticky
-   Transparent initially
-   Blur on scroll
-   Minimal links

------------------------------------------------------------------------

# Footer

Simple and elegant.

Contains: - Copyright - Social links - Small closing statement

------------------------------------------------------------------------

# Accessibility

-   WCAG AA contrast
-   Visible focus states
-   Keyboard navigation
-   Alt text for all images
-   Reduced motion support

------------------------------------------------------------------------

# Design Do's

-   Keep layouts clean
-   Use whitespace intentionally
-   Highlight work first
-   Maintain consistency
-   Optimize for performance

# Design Don'ts

-   Too many colors
-   Long text blocks
-   Decorative animations
-   Busy backgrounds
-   Inconsistent spacing

------------------------------------------------------------------------

# Brand Checklist

Before approving a page, ask:

-   Does it feel premium?
-   Does it showcase storytelling?
-   Is the layout simple?
-   Is motion subtle?
-   Does the work remain the hero?

If any answer is "No", refine the design before implementation.
